## Projects

### [Cautious Crypto Bro](https://github.com/Smarandii/cautious-crypto-bro)

Reads trading ideas from Telegram text and images, then turns them into orders on Bybit Demo. An LLM extracts the intent; Python code handles risk checks, order planning, and execution. Manual approval, persistent state, and recovery from interrupted operations are part of the design. No real-money trading.

### [ReClip + ASR Pipeline](https://github.com/Smarandii/reclip-with-asr-pipeline)

A local media downloader and transcription app. Runs Whisper on a GPU, keeps jobs and artifacts in SQLite-backed storage, and resumes work after restarts.

### [Subwhisperer](https://github.com/Smarandii/subwhisperer)

A Python CLI for turning videos into SRT subtitles and plain-text transcripts with FFmpeg and Whisper. I originally made it for my own video editing.
